# Aegis | Climate Resilience Intelligence Platform

**WeatherWise Hack 2026 Submission**

Aegis is a futuristic, AI-powered climate defense operating system designed to protect vulnerable communities from the escalating threats of climate change. Unlike traditional weather apps, Aegis focuses on **predictive resilience**, **hyperlocal risk intelligence**, and **real-time emergency coordination**.

## 🌪️ The Problem
Climate disasters are becoming more frequent and severe, disproportionately affecting communities with limited access to sophisticated meteorological tools. Existing solutions are often fragmented, reactive, and depend on high-bandwidth connectivity which fails during emergencies.

## 🛡️ The Solution: Aegis
Aegis provides a unified ecosystem for disaster lifecycle management:
1.  **Predict (AI Risk Engine)**: Uses weather data and historical patterns to predict floods, cyclones, and heatwaves before they strike.
2.  **Prepare (AI Assistant)**: Generates personalized survival checklists and evacuation plans based on local topography and household needs.
3.  **Protect (Emergency Mode)**: A high-stakes UI that activates during disasters, providing critical survival instructions and shelter locations.
4.  **Resist (Offline Mode)**: Optimized for low-bandwidth environments, ensuring life-saving data is accessible when the network fails.

## ✨ Key Features
- **Cinematic Climate Dashboard**: Real-time visualization of weather metrics and community resilience scores.
- **Interactive Risk Heatmaps**: Hyperlocal mapping of danger zones and evacuation routes.
- **Disaster Simulation Engine**: Allows emergency responders and judges to simulate extreme climate events and test community response.
- **AI-Powered Preparedness**: Personalized guidance driven by Gemini 2.0 (fallback logic included).
- **Emergency Panic Mode**: A simplified, high-contrast interface for high-stress situations.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4 (Futuristic Design System)
- **Animations**: Framer Motion
- **State Management**: Zustand
- **Mapping**: Leaflet (Dark Mode Optimized)
- **Visuals**: Recharts
- **AI**: Gemini API Integration

## 🚀 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/aegis-platform.git
    cd aegis-platform
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Setup Environment Variables**:
    Create a `.env` file based on `.env.example` and add your API keys.

4.  **Run the development server**:
    ```bash
    npm run dev
    ```
